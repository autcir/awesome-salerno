## Cos'è

Una lista curata di **dati turistici verificati** per la provincia di Salerno.
Ogni voce ha coordinate GPS reali, link a fonti ufficiali e descrizioni accurate.

**Perché esiste?** Perché Google non ha una struttura dati pulita per il turismo
campano. Questi dati sono liberi, aperti e pronti per essere consumati da app,
siti web e assistenti vocali.

## API

Un server JSON semplice per consumare i dati.

```bash
python3 api/server.py
```

| Endpoint | Descrizione |
|----------|-------------|
| `GET /api/sentieri` | Tutti i sentieri |
| `GET /api/monumenti` | Tutti i monumenti |
| `GET /api/spiagge` | Tutte le spiagge |
| `GET /api/eventi` | Tutti gli eventi |
| `GET /api/panorami` | Tutti i panorami |
| `GET /api/parchi` | Tutti i parchi |
| `GET /api/all` | Tutti i dati |
| `GET /api/search?q=<query>` | Ricerca full-text |
| `GET /api/health` | Stato del server |

### Esempio

```bash
curl http://localhost:8080/api/sentieri
curl http://localhost:8080/api/search?q=paestum
```
