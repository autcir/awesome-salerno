## Cos'è

Una lista curata di **dati turistici verificati** per la provincia di Salerno.
Ogni voce ha coordinate GPS reali, link a fonti ufficiali e descrizioni accurate.

**Perché esiste?** Perché Google non ha una struttura dati pulita per il turismo
campano. Questi dati sono liberi, aperti e pronti per essere consumati da app,
siti web e assistenti vocali.

### Fonti dei dati

| Fonte | POI | Descrizione |
|-------|-----|-------------|
| [OpenStreetMap](https://www.openstreetmap.org/) | 2672 | Churches, castles, museums, trails, beaches, parks |
| [Wikidata](https://www.wikidata.org/) | 1018 | Nature, viewpoints, attractions |
| Manuale | 94 | Curated data with verified links |
| **Totale** | **3615** | All with valid GPS coordinates |

## API

Server JSON per consumare i dati.

```bash
python3 api/server.py
```

| Endpoint | Descrizione |
|----------|-------------|
| `GET /api/sentieri` | Tutti i sentieri (318) |
| `GET /api/monumenti` | Tutti i monumenti (2600) |
| `GET /api/spiagge` | Tutte le spiagge (126) |
| `GET /api/eventi` | Tutti gli eventi (8) |
| `GET /api/panorami` | Tutti i panorami (544) |
| `GET /api/parchi` | Tutti i parchi (19) |
| `GET /api/all` | Tutti i dati (3615) |
| `GET /api/search?q=<query>` | Ricerca full-text |
| `GET /api/health` | Stato del server |

### Esempio

```bash
curl http://localhost:8080/api/sentieri
curl http://localhost:8080/api/search?q=paestum
curl http://localhost:8080/api/search?q=ravello
```
